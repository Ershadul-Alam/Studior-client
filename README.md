# Studior

Studior is a modern studio discovery and booking platform built with Next.js.

**Live link:** https://studior-one.vercel.app

## Features

- Browse and search available studios
- View studio details
- List a studio
- Create an account and sign in
- Manage bookings and profile information

## Tech Stack

- Next.js
- React
- TypeScript
- Tailwind CSS
- Better Auth
- MongoDB
